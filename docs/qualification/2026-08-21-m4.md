## Findings and tuning applied

The first run found that every reconciliation retained all historical full
generations. The #21 branch now deletes generations no longer referenced by
`published_roots` in the publication transaction and enables full auto-vacuum for
new File Indexes. Existing-index startup now opens a generation-validated Search
Projection directly instead of loading every SQLite row and rebuilding the
projection before showing committed results.

The remaining disk and Catching Up RSS failures require a more compact projection
and streaming reconciliation; those are product changes, not evidence that can be
papered over in a qualification report.

## Follow-up tuning run

The compact-projection follow-up used 1,175,006 published real Home entries:

- compact SQLite after `VACUUM`: 203,588 KiB;
- Search Projection with directory interning, normalized names, and five empty-query
  sort indexes: 148,084 KiB;
- combined storage: approximately 292 MiB per million entries (pass);
- representative non-empty query across all six ascending sorts: p95 79.8–85.5 ms,
  p99 80.6–87.3 ms (pass);
- empty query across all six ascending sorts: p95 10–18 µs, p99 14–28 µs;
- projection benchmark maximum RSS: 154,402,816 bytes; measured peak footprint
  19,235,320 bytes;
- stable Current release app: 93,568 KiB RSS and 0.0–0.2% CPU across twelve
  five-second samples (approximately 0.1% average; pass);
- 10,000 ordinary file additions scanned, transactionally published, projected,
  and searchable in 232 ms (pass);
- Balanced live file creation appeared as a result within the first UI check and
  well inside 10 seconds (pass).

The compact schema stores each path once in a `WITHOUT ROWID` table and prunes old
generations in the publication transaction. The projection interns parent paths,
borrows mmap strings during queries, and streams directly from SQLite. Scoped
reconciliation copies unchanged rows inside SQLite rather than materializing the
entire committed generation in Rust memory.

that hardware-specific acceptance item.
